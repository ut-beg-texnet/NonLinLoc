GridCut - extracts a sub-volume from a NLL `3D grid`
=========================================================================

Given an existing NLL `3D grid` (.buf and .hdr file pair),  **GridCut** generates a new NLL `3D grid` consisting of a specified sub-volume of the existing grid, or a sub-volume of the existing grid centered in x/y (lat/lon) at a specified station source and with specified extent.


Overview
--------

**GridCut** generates a specified sub-volume of and existing grid based on a standard, NLL grid description, (e.g. `3D grid` Header file first line), describing the size and type of a `3D grid`.

**GridCut** centers the new, sub-volume grid at a specified station source if an optional, NLL `3D grid` Header file second line (describing the label and x, y, z location of a source/station) is present.
This option is useful for extracting smaller 3D velocity grids around each station from a large 3D velocity grid before calculation of travel-times, greatly improving travel-time calculation and NLLoc location run-time efficiency relative to using velocity and travel-time grids for the full 3D region for each station.


Running the program
---------------------------

Synopsis: ``GridCut inputGridRoot outputGridRoot outputGridDescription [sourceDescription]``

The **GridCut** program is run on the command line and uses command line arguments, not a NLL `Input Control
File`.

Program arguments:

``inputGridRoot`` - full or relative path and file root name (no extension) for input NLL `3D grid`

``outputGridRoot`` - full or relative path and file root name (no extension) for output, sub-volume NLL `3D grid`

``outputGridDescription`` - NLL grid description (e.g. ``VGGRID`` Source Description) specifying the sub-volume to extract from the input grid.

``sourceDescription`` - optional NLL source description (e.g. ``GTSRCE`` Source Description as used for ``Grid2Time``). If present, the output sub-volume grid will be centered at the specified source, the grid origin in ``outputGridDescription`` will be ignored, and the output grid extent will be derived from the ``outputGridDescription`` number and spacing of grid nodes.

If an ``outputGridDescription`` source is specified, **GridCut** outputs a profile of grid values (e.g. a 1D, vertical velocity profile) below the source to file ``outputGridRoot``.profile.in.
A 1D model profile can be used to calculate 2D travel-times (travel-time vs distance, depth) for a station source, including for points outside the `3D grid` sub-volume generated by **GridCut** .


Output
------

The extracted, sub-volume `3D Grid` is written to a new `3D Grid` .buf and .hdr file pair with root name ``outputGridRoot``.
